This estimates a tempo trajectory from attacks and strums, checking each beat period and its next three repetitions together. Continuity is regularized per elapsed second to reduce switches between beat groupings while allowing acceleration and slowing. Independent local winners are retained in CSV/JSON and tooltips. Clarity is a heuristic evidence score, not a probability. Musical beat interpretation can still be ambiguous. Adjacent windows overlap and are not independent measurements.

The source file is unchanged. This report works offline and makes no network requests.
